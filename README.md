# 🎮 学芸クエスト（Gakugei Quest）

浜松学芸高等学校を舞台にした **2D RPG** です。

高校2年生の授業で、4人のチームで制作しました。  
私は**エンジニア**を担当し、既存のRPGシステムを読み解きながら、ゲームへの実装や新しい機能の追加・改良を行いました。
短い時間で楽しめるように２階までの要素を多く詰め込みました。このゲームは２階までのプレイを想定して作っています。

## 💻 主な追加・変更

### 🎬 イベントシステムの拡張

学校内でさまざまなイベントや演出を作れるように、既存のイベントシステムを拡張しました。

新しく追加したイベント処理には、以下のようなものがあります。

- **NPCを移動させる**
- **NPCの向きを変更する**
- **オブジェクトの当たり判定範囲を変更する**
- **オブジェクトを削除する**

これらをフラグなどの既存システムと組み合わせることで、イベントの進行に合わせてNPCやマップ上のオブジェクトを変化させられるようにしました。

例えば、イベントの途中でNPCを指定した位置まで移動させて向きを変更したり、条件を満たすことでオブジェクトの当たり判定を変更して通行できるようにしたり、役目を終えたオブジェクトをマップから削除したりできます。

### ⚔️ 戦闘システムの変更・拡張

ベースとなった戦闘システムを、学芸クエストの仕様に合わせて変更・拡張しました。

- 通常攻撃の処理
- 魔法攻撃の処理
- 回復魔法の処理
- 敵が使用する魔法の処理
- ダメージ・回復計算の調整
- 敵のHPが0になった際の処理
- 勝利時のメッセージ表示タイミングの調整
- 戦闘終了後の処理
- 逃走条件の調整
- 戦闘中に発生した不具合の修正

### ✨ 魔法システムの変更・拡張

ゲームの進行に合わせて魔法を利用できるよう、魔法関連の仕組みを変更しました。

魔法データでは、以下の情報を管理しています。

- 魔法ID
- 魔法名
- 説明
- 消費MP
- 魔法の効果
- 解放条件

また、**フラグによって魔法を解放する仕組み**を追加し、ゲーム内のイベントや進行状況に応じて使用できる魔法を変えられるようにしました。

### 👾 敵の行動処理

敵の行動に関する処理を学芸クエストに合わせて変更しました。

敵は状況に応じて、**通常攻撃**や**魔法**などから行動を選択します。

魔法を使用する場合には、必要なMPを持っているかなどを確認して行動を決定するようにしています。

### 🚩 フラグによるゲーム進行管理

イベントや魔法など、ゲーム内の状態を管理するためにフラグを利用しています。

フラグを利用することで、以下のようなゲーム進行の制御を行っています。

- イベントの発生条件を変更する
- 一度発生したイベントの状態を保持する
- 条件を満たしたときに新しい魔法を解放する
- NPCやオブジェクトの状態を変化させる

### 🔊 BGM・SE

ゲーム内のBGM・SEに関する処理を調整しました。

- BGMの再生・切り替え
- SEの再生
- 戦闘開始時のBGM処理
- 戦闘中のSE処理

### 🗺️ ゲーム内容の実装

プログラムそのものの追加・変更だけでなく、チームで制作した内容を実際のゲームとして動作させるための実装も担当しました。

- マップへのNPCやオブジェクトの配置
- NPCの会話の実装
- イベントの設定
- 敵や戦闘の設定
- ゲーム内データの設定
- 素材のUnityへの組み込み
- 各機能を組み合わせたゲーム進行の実装

### 🐛 デバッグ・不具合修正

制作中に発生した不具合について、原因となっている処理を調べて修正しました。

特に、戦闘・イベント・魔法など複数のシステムが関係する部分では、既存コードを追いながら原因を特定し、正常にゲームを進行できるよう修正を行いました。

## 📚 制作を通して学んだこと

学芸クエストの制作を通して、ゲームは一つのプログラムだけで動いているのではなく、キャラクター、戦闘、イベント、データ管理、サウンド、UIなど、さまざまな仕組みが連携することで成り立っていることを学びました。

特に、既存のプログラムを読み解いて機能を追加する経験から、プログラムを動かすだけではなく、**既存の仕組みを理解し、自分たちが実現したいゲームに合わせて変更・拡張していくことの重要性**を学びました。

## 🛠️ プロジェクトを開く

1. このリポジトリをCloneまたはダウンロードします。
2. Unity Hubを起動します。
3. ダウンロードしたプロジェクトを追加します。
4. **Unity 6000.0.3f1** でプロジェクトを開きます。

> **Note**  
> 本プロジェクトは **Unity 6000.0.3f1** で制作しています。  
> 異なるUnityバージョンでは正常に動作しない可能性があります。
